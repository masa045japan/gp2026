# gp2026は，何のプロジェクトですか？
ゲームプログラミングおよび演習2026用のスクリプトとFAQのプロジェクトです

# 成績評価方法は？
### 作品50%
制作したゲームの制作物一式，最終プレゼンテーション資料等を含む
### 課題50%
企画書，制作したゲームのプロモーション動画，プレゼンテーション資料，ポートフォリオ等を含む
### その他
他チームの作業に協力した場合に加点する場合があります(最大10%)

# 生成AI等を利用する上での注意事項は？
### ゲーム制作で生成AIを利用する場合
プログラムの開発・デバッグ支援，イラスト・BGM・効果音等の作成支援等で生成AIを利用する場合，制作物（ゲーム中のクレジット）及び提出物（itch.ioへの掲示物等）に，利用箇所・方法，利用した生成AIを明記すること
### ゲーム制作で自作以外のイラスト・BGM・効果音・フォント・OSS等を利用する場合
各ライセンス条項に準拠した上で，制作物と提出物に上記と同様明記すること
### 他社IPの利用，二次創作は禁止とする
